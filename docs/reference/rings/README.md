# Reference rings — the Phase 3 (ring styles) spec

Twelve rings Mark collected on 2026-10-30 as the target for Phase 3. Product photos kept for
design study only (private repo). Each line says what the ring needs beyond what the pipeline
builds today; the numbers in brackets are the Phase 3 capability groups in `docs/plan.md`.
