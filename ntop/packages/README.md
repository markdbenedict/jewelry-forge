# Packages

nTop's community-package layout, used here to version and describe each block:

```
packages/<block-id>/
  manifest.json   id, type, title, summary, author, version (semver), ntopVersion, license, tags
  README.md       what it does, inputs/outputs, how to install, usage
  cover.png       optional
```

The `.ntop` itself lives in `ntop/blocks/`. Reference:
https://github.com/nTopology/Utilities-community
